# 🎬 Netflix Content Analysis Dashboard

An exploratory data analysis and interactive Power BI dashboard analyzing 8,700+ Netflix titles across genres, ratings, and global distribution.

## 📊 Dashboard Features
- Movies vs TV Shows breakdown
- Content growth over time (peak: 4,500 titles in 2019)
- Top genres ranking
- Ratings distribution
- Global content map by country

## 🔍 Key Insights
- 69% of Netflix content is Movies
- TV-MA dominates with 7,300+ titles
- International content is the fastest growing genre

## 🛠️ Tools & Technologies
Python | Pandas | Power BI | Excel | Kaggle Dataset
